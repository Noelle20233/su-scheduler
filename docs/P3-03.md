## 2. 设计（Registry 正式调度链）

```
Registry Task（正式数据源：managed=task-config 快照 / legacy=config.txt 投影）
    │  sched_reload（原子；源指纹 md5 判定；损坏 → KEPT 最后有效快照）
    ▼
scheduler_tick（每 tick：源重载 + 逐任务）
    │  TriggerProvider（trigger_decide：boot/time/advanced/run-once-now）
    ▼ due=Y
ActionProvider（action_run：SYSTEM/TERMUX/INTERACTIVE/APP + notify/msg）
    ▼
Runtime State（state.txt/events.log 双写，P2-07）
    ▼
Supervisor（health/recovery/retry，P2-12/13；快照移除任务经 task.v2 兜底）
```

**禁止继续出现**：Registry 只做日志、legacy config 扫描才真正执行 —— 当
`RUNTIME_LOADED=1` 时 daemon 主循环**只经 scheduler_tick** 获取任务。

## 3. 双模式控制

| 模式 | 判定（`sched_source_mode`） | Registry 来源 | 行为 |
| :-- | :-- | :-- | :-- |
| **managed** | `task-config/MANAGED` 存在 | `sched_snapshot_managed`（从 task-config/*.task 重建快照，**不重扫 config.txt**） | 执行只来自 Registry |
| **legacy** | 无 MANAGED | `registry_reload(config.txt)`（KEPT 回退最后有效快照） | 与既有 legacy 语义一致（config.txt 是权威，Registry 是其投影） |
| **fallback** | `RUNTIME_LOADED=0` | 无（不加载 lib） | daemon 走既有 config.txt 扫描执行（C2 原样） |

## 4. 语义保证（需求逐条）

| 需求 | 实现 | 测试 |
| :-- | :-- | :-- |
| daemon 启动加载当前有效 Registry | 启动段 `sched_reload`（managed）/ `shadow_init+lifecycle_startup_registry`（legacy） | §2/§6 |
| 主循环只通过 Registry 获取任务 | `scheduler_tick`（RUNTIME_LOADED=1）替代 legacy config.txt 扫描 | §3/§10 |
| TriggerProvider 判断到期 | `sched_execute_one` → `trigger_decide` | §3/§10 |
| ActionProvider 执行 | `sched_execute_one` → `action_run` | §3/§7 |
| 保留 Legacy fallback | daemon `else` 分支 config.txt 扫描原样（action_run/execute_task 各 4 处） | §1/§10 |
| Managed 不再重扫 config.txt | managed 下 `sched_reload` 只从 task-config；daemon 主循环不扫 config.txt | §7 |
| 保留 heredoc/ron/delete/Termux/Interactive | 任务文件字段经 action_run 原样透传；ron/delete 后置语义（§20 `sched_prune_ron`/`sched_remove_task`） | §3/§7 |
| 保留旧运行目录/旧运行 ID | 执行落 `tasks/<id>`（canonical）；idmap（§9）双向映射；旧 CLI 读取不变 | §8 |
| 配置 reload 原子切换 | reload 只写新快照 + 原子 flip `current` 指针（tmp+mv）；损坏 → KEPT | §5/§6 |
| 快照移除的运行任务继续监督 | 执行时 stash `task.v2`；`supervisor_task_file` 兜底读取 | §9 |
| 单 Task 错误不退出 daemon | `scheduler_tick` 逐任务 rc 隔离，continue；坏任务只记 audit | §10 |
