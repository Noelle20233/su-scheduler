## 2. 设计（四支柱）

```
webroot/ Task Editor（分步表单）
   │  前端校验一次（不构成安全边界）→ 组装完整 Task v2 内容
   ▼
IPC：GET_TASK_EDIT（回显原文）/ VALIDATE_TASK（payload 全字段校验预览）/ EDIT_TASK（完整内容原子写入 + reload）
   ▼
Runtime §23：tcfg_editor_validate_payload（后端再次校验，权威）tcfg_apply_task（tmp+mv 原子写）
   ▼
task-config/（Managed 权威存储）→ daemon reload → Supervisor 读取
```

- **前后端双重校验**：前端 validateForm 只用于即时反馈；后端 tcfg_editor_validate_payload 是唯一安全边界。
- **表单 schema**：TASK_FORM_SCHEMA（webroot/app.js）+ docs/architecture/task-editor-schema.md（规范）。
- **保存原子化**：tcfg_apply_task 先校验（非法不写盘）→ tmp+mv 原子；失败不留半成品、旧文件逐字节不变。
- **编辑不产生重复 ID**：ID 是文件主键，EDIT_TASK 按 id 原子覆盖同一文件。
- **未实现 Trigger 明确禁用**：boot_completed/delay/interval/cron/oneshot 前端 disabled + 后端拒绝。

## 5. WebUI Task Editor（webroot/）

| 步骤 | 字段 |
| :--- | :--- |
| Basic | ID / Name / Enabled / Description |
| Trigger | 类型（boot/time/weekly/nweekly/monthly/nmonthly/yearly；未实现族禁用）+ 参数 |
| Action | Command / App（package/activity/broadcast/service） |
| Health | None / Process / Port + target |
| Recovery | None / Restart / Start / Stop+Start / Script（绝对路径） |
| Retry | Max / Interval / Cooldown |
| Advanced | Timeout / Environment / Concurrency / Logging |

- **校验预览**：validateForm（前端）→ VALIDATE_TASK payload（后端全字段校验）。
- **保存**：EDIT_TASK → 成功「已保存 ✓」/ 失败「保存失败（旧配置未变）」。
- **取消**：丢弃表单返回 Task List。渲染走 textContent；WRITE_OPS 白名单。

## 6. 安全声明（对照验收逐条）

| 验收条款 | 机制 | 测试证据 |
| :--- | :--- | :--- |
| 所有字段前端校验一次 | validateForm | editor §static |
| 所有字段后端再次校验 | tcfg_editor_validate_payload | validation 全矩阵 |
| 前端校验不能作为安全边界 | 后端独立实现 + IPC 再校验 | validation §back |
| ID 不允许路径穿越 | tcfg_editor_id_ok | validation §id |
| App Action 复用 P2 结构化校验 | tcfg_editor_action_ok → tpr_action_app_validate | editor §app-inject |
| recovery script 绝对路径且可读 | tcfg_editor_recovery_ok | validation §recovery |
| 所有数值有范围限制 | tcfg_editor_num | validation §num |
| 所有保存操作原子化 | tcfg_apply_task tmp+mv | validation §atomic |
| 合法 Task 保存并重新加载 | EDIT_TASK → reload → GET_TASK_EDIT 回读 | editor §save-reload |
| 非法 Task 无法保存 | rc4 configuration_invalid 不写盘 | editor §reject |
| 保存失败旧配置不变 | md5 前后比对 | editor §atomic |
| 编辑不产生重复 ID | ID 文件主键 | editor §no-dup |
| App Action 注入全部拒绝 | 恶意 spec → rc4 + md5 不变 | editor §app-inject |
| Health/Recovery 可被 Supervisor 读取 | supervisor_health_spec 直接读保存字段 | editor §supervisor |
