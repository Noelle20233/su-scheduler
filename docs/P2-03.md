## 2. 设计（§8 Shadow Mode）

**旁路原则（C2）**：不消耗 daemon 扫描结果、不触发任何执行/修剪、不改 legacy
路径——仅建快照并比对记录。

1. **启动快照**：shadow_init 调 registry_init 建首快照，legacy 镜像扫描 ↔
   registry 触发器集基线比对，写 shadow.last（原子 tmp+mv）与 shadow.log。
2. **配置变化 → 原子 reload**：shadow_tick 每轮比对 config md5；变化 →
   registry_reload（新快照独立目录 + current 指针 tmp+mv 原子切换，无混合态）；
   未变 → 沿用当前快照（不刷快照号）。
3. **配置损坏 → KEPT**：reload 无效 → 删除未提交快照、指针不动，继续用最后
   有效快照；shadow 记 agree=N + diff。
4. **一致性记录**：shadow.log 追加 `<ts>|SHADOW|op=<init|reload|compare>|agree=
   <Y|N>|legacy=<n>|registry=<m>|snap=<id>|cfg_md5=<12>`；agree=N 时另记 diff
   行；shadow.last 存 last_md5/last_snap/last_agree/last_legacy/last_registry。
5. **命名空间**：§8 全 shadow_* 前缀，无 legacy 同名冲突；dash -n 通过。

**daemon 接线（两处，均 RUNTIME_LOADED 门控）**：
```sh
if [ "$RUNTIME_LOADED" -eq 1 ]; then shadow_init "$DATA_DIR" "$CONFIG_FILE" "$DATA_DIR/shadow/shadow.log" >/dev/null 2>&1; fi
# 主循环 mtime 检测后、legacy 扫描前：
if [ "$RUNTIME_LOADED" -eq 1 ]; then shadow_tick "$DATA_DIR" "$CONFIG_FILE" "$DATA_DIR/shadow/shadow.log" >/dev/null 2>&1; fi
```
库缺失/损坏 → RUNTIME_LOADED=0 → 旁路不触发，daemon 纯 legacy（P2-02 fallback 延续）。
