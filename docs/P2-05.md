## 1. 设计（Runtime 库 §10 Trigger Decision Layer，v1.2.0 → 1.3.0）

- **单一正式入口**：`trigger_decide <base> <task_id> [now] [boot] [state_file]` —
  boot / time / advanced 三家族一律经 `provider_dispatch trigger <family> matches`
  （P1-04 唯一分发入口）；lib 中 dispatch-trigger 调用恰 3 处、`trigger_decide`
  仅定义 1 次。**旧判断保留为 fallback**（daemon 内联决策原样，C2）。
- **保留语义（C4）**：
  - **heredoc**：source.type=block 任务与单行同触发器语义（决策按 trigger 字段）；
  - **--run-once-now**：首扫即 due（cause=manual_exec）；**零修剪**（修剪动作仍归执行层）；
  - **--delete**：仅动作语义（本层零删行、零改配置；action.delete=1 保留在任务镜像）；
  - **既有去重状态**：advanced 决策**只读**状态文件（键检查沿用 §10
    `trigger_adv_key` 镜像构造；**写仍归 legacy 执行路径**——本层零写入）。
- **不引入**：Dependency / Condition / 新 Trigger（仅 boot/time/advanced 家族）。
- **接线（su-schedulerd，两处，均 RUNTIME_LOADED 门控；旁路，不改 legacy 执行路径）**：
  - 启动块：`for tid in $(registry_task_ids); do trigger_decide ... >> "`$DATA_DIR`/shadow/shadow.log"; done`；
  - 主循环块：同一循环（now 取当前分钟、boot=0）。
