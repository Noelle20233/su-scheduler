## 4. 前端改动（webroot/app.js + style.css）

### 4.1 周期刷新机制
- 新增 `startRefresh(view, fn, intervalMs)` / `stopRefresh()`：`setInterval` 轮询当前视图的
  `read()` 拉取；默认 Dashboard/Task Detail 5s，Task List 10s；hashchange 时清理旧 interval
  再启新（防止泄漏）。
- 刷新指示：view 顶/角落显示「上次更新 HH:MM:SS」+「刷新中…」状态。

### 4.2 刷新失败保留上次数据
- 重构渲染：`renderX()` 前保存 `lastViewData` 缓存；`read()` 失败或 `!data.ok` 时**不清空
  view**，叠加错误横幅（`offlineBanner` 样式化，含 rc/error 信息）+「上次数据已过期」标记，
  保留缓存渲染。恢复成功时清除错误横幅。

### 4.3 状态展示增强
- Dashboard/Task List：补 **waiting/unhealthy/recovering** 计数卡（只增，不删既有卡）。
- Task Detail 状态卡：补 WAITING/RECOVERING 高亮（`.st-WAITING`/`.st-RECOVERING`）。
- Task Detail kv 块：**补渲染** `dependency`/`condition`/`dependency_state`/`gate_state`/
  `condition_state`（textContent，防注入）；gate_state 含依赖失败/超时原因直接展示。

### 4.4 最近事件 / 执行时间
- Task Detail：「加载运行历史」按钮保留；新增默认显示**最近事件**（`last_event` 字段，若有）+
  执行耗时（前端由 `last_end - last_start` 计算 `last_duration`，不在后端膨胀）。
- events 行结构化渲染（可选增强）：ts/event/state/msg 分列。

### 4.5 安全（D28 + P5-09 复核基线）
- 全部动态内容继续 `textContent`；错误横幅信息（rc/error）同样 textContent；不引入
  innerHTML/eval/su/sh -c。新增字段值均经 `web_json_escape`（后端）→ 前端 textContent 双保险。
