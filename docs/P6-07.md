## 4. 实测 run.txt 片段（引擎产出）

daemon 重启恢复（R7，A 进程崩溃于 b 在途 → B 进程 recover+续跑）：

```
chain=lr  run=202609080830  state=SUCCESS          # 崩溃前: b|chain|RUNNING|disp（pid.txt=死 pid）
root=lr|STOPPED|1                                  # recover: b --daemon_restart--> FAILED
lb|chain|STOPPED|disp        # 节点级重试 1 次（attempt 1/2）→ 成功翻正，非引擎重放
lc|chain|STOPPED|disp  ld|chain|STOPPED|disp      # 各恰 1 次执行；run 数恒 1（同 token 不重复建）
---
chain=lr2 run=202609080830  state=FAILED           # 无重试预算兄弟链：
lb2|chain|FAILED|disp（stale→FAILED） lc2|chain|FAILED|gate-fail   # → 传播终局，有界
```

删除/禁用/残树（P7-09 / EX-11 / P7-10 / fuzz）：

```
root 删除：账本前滚 root=rt0|STOPPED|1 冻结，成员照常收敛 state=SUCCESS（无永久 RUNNING）
disable：b|chain|PENDING|disabled → c waiting → action=timeout run=FAILED（b/c 零执行）
孤儿/残 run：state=PENDING → 超时 FAILED → prune 域 → dag_active_runs 释放名额
```
