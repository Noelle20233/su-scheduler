## 3. 输出契约（样例为真实运行截取）

### 3.1 `task status`（追加行；既有行序零改动）

链节点：
```
chain_root=ra
role=node
run=202609080830
run_state=SUCCESS
node_state=STOPPED
note=disp
reason=
last_tick_catchup=0
catchup_executed=1
```
- `last_tick_catchup=<n>`：末条 `op=tick` 的聚合补偿计数（审计尾读，稳于 last_tick 现算）；
- `catchup_executed=0|1`：该任务是否存在 `catchup=1` 标记的 op=exec 审计行（曾被补偿执行）；
- 链七键仅链相关任务出现（role 非空=账本事实源判定，与 WebUI 完全一致）；非链任务零链行（A3 红线）。

### 3.2 `task-info <id>`（managed 域追加标签）

```
Upstream: rt0 (required want=STOPPED via=chain); aux (optional want=STOPPED via=chain)
Downstream: c (required want=STOPPED via=chain)
Last Tick Catchup: 1
Catchup Executed: 0
Chain Root: rt0
Role: node
Run: 202609080830
Run State: SUCCESS
Node State: STOPPED
Node Note: disp
Reason: dep failed: b(FAILED want STOPPED)
Member Of Chains: ra rb        # 仅多根共享时出现（P6-08 口径：主行=字典序首链）
```
`via=chain|gate` 区分链边与 P4 依赖门；`(required|optional) want=<STATE>` 承载 `?`/`:STATE` 语义。

### 3.3 `su-scheduler chain`（只读；语法裁决见 §7）

```

member=c state=STOPPED note=disp
```

## 4. 审计变更清单

| 变更 | 行样例 | 兼容性 |
| :--- | :--- | :--- |
| `op=exec` 尾字段（仅 catch-up 上下文） | `...|cause=time_trigger\|catchup=1` | 常规执行行以 `cause=` 结尾**逐字节不变**（scheduler_tick 补偿分支置 `sched_exec_catchup=1`，try/finally 式复位） |

## 7. 与任务书的差异/解释性决策

1. **`chain` 语法**：任务书 `chain [root|<chain-id>]` 的 "root（列全部链根）"语义由**无参形态**承载（对齐 `task list`/`task-config list` 惯例，不引入字面量子词；`-h/--help` 提供 usage）。
2. **`task info <id>` 落点**：既有生产 CLI 无 `task info` 子命令；任务书该面 = 既有 `task-info <id>`（P5-08 managed 追加标签通道），EX-17c 命名亦指 `task status/info`。未新增 `task info` 别名（最小改动面；如需别名 P7 一行可加）。
3. **节点完成审计 = run 级**：任务书建议格式 `op=dag|action=complete|chain=..|run=..` 无 `task=` 字段 → 实现为 run 终态回写一条（nodes/failed 汇总入行）；节点级终态可由 `member=` 账本行与 dispatch/fail-propagate 既有审计推导。
4. **reason 超时扩展仅在 CLI 文本面**：`task status`/`task-info` 的 `reason=run-timeout`（审计尾读 action=timeout）为 CLI 追加；WebUI `dag.reason` 键面逐字节不动（D58 只增键契约零触碰，p6-webui 守卫）。
5. **多根共享用例拓扑**：跨根 required 边在对方 run 账本外恒 `waiting-missing`（D51 语义，非缺陷），共享节点展示面以 `?` 可选边构造（F1：`note=disp opt-unsat`）。
6. **`tests/p6-dag`/`p6-reliability` 未注册 run_tests.sh**（沿 P6-02/P6-06 既有惯例，两套件由任务验收命令单跑）；仅新套件 p6-cli 注册。
7. **chain 图目录回退**：快照缺失/KEPT（图非法）时 `chain` 的现图读 `task-config` 权威目录（与 P5-07 `dep_errors` 同源），保证运维面在坏图下仍可用。
