## 4. 加载失败 fallback（明确契约）

daemon 与 CLI 头部加载块（同一表达式）：

```sh
RUNTIME_LIB="/system/bin/su-scheduler-runtime"
RUNTIME_LOADED=0
if [ -f "$RUNTIME_LIB" ] && [ -r "$RUNTIME_LIB" ]; then
    . "$RUNTIME_LIB" 2>/dev/null && RUNTIME_LOADED=1 || RUNTIME_LOADED=0
fi
if [ "$RUNTIME_LOADED" -eq 1 ] && ! runtime_lib_selfcheck >/dev/null 2>&1; then
    RUNTIME_LOADED=0
fi
```

- 库**缺失 / 不可读 / 语法破损 / selfcheck 不通过** → `RUNTIME_LOADED=0`，
  **legacy 路径原样继续**（本库是叠加层，不修改既有行为路径——C2）。
- daemon：启动时记录一次 `[WARNING] ⚠️ Runtime library unavailable…; legacy
  mode active`（不中断、不重试、不降级功能）；加载成功记 `[INFO] ⚙️ Runtime
  library loaded (v1.0.0)`。
- CLI：`RUNTIME_LOADED` 置位即止，**不向 stdout 输出加载噪音**（保持既有输出
  稳定）。
- 门禁断言（tests/runtime-lib）：缺失 → 0、语法破损 → 0、有效 → 1，均无错误
  中止。
