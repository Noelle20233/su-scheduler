## 3. FAIL→PASS 证据（D34）

**修前（HEAD `44a431e`，Runtime 1.27.0，未含 §hard-p4-10）**：

```bash
git show HEAD:system/bin/su-scheduler-runtime | grep -nE '\$\{[A-Za-z_][A-Za-z0-9_]*#\*\|'
# → 3697: 注释（P3-10 D-IPC 说明）
# → 5518: depg_targets=${depg_adjline#*|}     ← 生产缺陷（dep_validate_graph）
# → 5552: depg_targets=${depg_adjline#*|}     ← 生产缺陷（depg_dfs）
```

- 新增 §hard-p4-10 静态断言「生产脚本零 `${var#*|}`/`${var%%|*}` 残留」在 HEAD
  runtime 上 **FAIL**（5518/5552 命中）；
- `cut -d'|' -f2-` 调用点 = 既有 7 处（ipc_parse/tctl_*）+ 修复后 2 处 = 9 处，
  断言「≥3」满足。

**修后（Runtime 1.28.0）**：

```bash
grep -nE '\$\{[A-Za-z_][A-Za-z0-9_]*#\*\|' system/bin/su-scheduler-runtime | grep -v '^[0-9]*: *#'
# → （空）：生产代码零残留
grep -n "cut -d'|' -f2-" system/bin/su-scheduler-runtime
# → 3700/3702（ipc_parse）、5520/5555（依赖图邻接表，D34 修复）、4765/4829/4860/4876/4902（tctl_*）
```

- 依赖图校验行为不变（邻接行恒含 `|`，`cut -f2-` 与 `${var#*|}` 产出等价）——
  既有 §graph/§apply/§set/§import/§snapshot 断言全部保持；
- §hard-p4-10 13 条断言转 **PASS**；§const/§dep/§norm/§cond/§editor/§store/§cli/
  §graph/§apply/§set/§import/§snapshot/§gate/§gate-p4-05/§cond-p4-06/§retry-p4-07/
