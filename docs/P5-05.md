## 2. 设计决策

### 2.1 接线架构

| 家族 | Provider | trigger_decide cause | matches 判定 |
| :-- | :-- | :-- | :-- |
| `boot_completed` | `tpr_trigger_bootcompleted` | `boot_completed` | `TRIGGER_BOOT_COMPLETED_CONTEXT=1` 且 schedule_state 无 `bc_<tid>` 键 |
| `oneshot` | `tpr_trigger_oneshot` | `oneshot` | 当前 HHMM == `oneshot:HHMM` 精确分钟 |
| `delay` | `tpr_trigger_delay` | `delay` | schedule_state `dl_<tid>` 缺失 → 写基准=now 并 due；否则 `now_epoch_min >= base + N` 且未执行 |
| `interval` | `tpr_trigger_interval` | `interval` | `now_epoch_min - last_epoch_min >= N`（缺 last → due） |
| `cron` | `tpr_trigger_cron` | `cron` | 5 段全字段匹配当前时间且 schedule_state 无 `cn_<tid>` 键（日级去重） |

### 2.2 rearm 状态持久化（schedule_state.txt）

- **键格式**（`<base>/schedule_state.txt`，与 advanced 家族同文件，registry 侧新增写路径）：
  - `dl_<tid>=<epoch_min>`（delay 基准=首匹配时刻）
  - `iv_<tid>=<epoch_min>`（interval last-run）
  - `cn_<tid>=<YYYYMMDD>`（cron 日级去重键）
  - `bc_<tid>=<YYYYMMDD>`（boot_completed 一次性去重键）
- **时间基准**：`date +%s`/60（epoch 分钟），避免 HHMM 午夜回绕（23:59→00:00 负差）。
- **写入点**：`sched_execute_one` 后置（delete/ron/oneshot 自删**之前**写 last-run，
  避免任务被删后键无意义；即使 action 失败也写 last-run——interval 是"每 N 分钟尝试"）。
- **不违反"派生字段不存储"契约**：schedule_state 本就承载周期触发器的 last-run 状态
  （nweekly 存 week、nmonthly 存 month 同类别）；last-run 是必要运行状态，非可推导派生字段。

### 2.3 oneshot 自删

- `sched_execute_one` L3597-3601 与 `sched_advance_waiting` L3481-3485 两处 delete/ron
  后置块并列新增：`elif` trigger 为 `oneshot:*` → `sched_remove_task`。
- 语义：oneshot 到点执行后自动移除（等价持久 delete，D43）。
- `trigger_decide` 被两条路径共用 → oneshot matches 只需一处实现。

### 2.4 daemon boot_completed 上下文

- daemon 主循环（L737-742）每 tick 检测 `getprop sys.boot_completed`，=1 时置
  `TRIGGER_BOOT_COMPLETED_CONTEXT=1`（shell 变量，一旦置 1 保持），并 export 到
  `scheduler_tick` 上下文。
- runtime `trigger_decide` 的 `boot_completed` 分支注入 `TRIGGER_BOOT_COMPLETED_CONTEXT`
  到 `provider_dispatch trigger bootcompleted matches`。
- 去重：`bc_<tid>` 键防跨 tick 重复（每次 tick 都会 matched 除非已写键）。

### 2.5 cron 求值

- 复用 P5-04 `tcfg_trigger_cron_field_ok` 校验 + 运行时逐段匹配当前
  min/hour/dom/mon/dow（用 `tpr_ctx_date %M/%H/%d/%m/%u` 镜像测试确定性）。
- 支持 `*` / `*/N` / `a,b,c` / 单数字 四种段形态（字段值匹配即段匹配）。
- 日级去重：`cn_<tid>=YYYYMMDD` 防同一天重复执行同分钟多次 tick。
