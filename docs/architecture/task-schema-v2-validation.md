## 1. 校验四原则

| # | 原则 | 含义 |
| :-- | :--- | :--- |
| P1 | **lenient** | 缺省兜底优先：字段缺失/非法 → 回退缺省值并告警，**不是**整体拒绝 |
| P2 | **条目隔离** | 错误只影响出错的 Task 条目（隔离/回退），**绝不**影响其他条目 |
| P3 | **绝不致命** | 任何单条目错误不得导致 daemon 退出、崩溃或死循环 |
| P4 | **绝不破坏存量** | 加载失败保留上一快照/现有条目；**绝不**因一个错误清空注册表或删除其他条目 |

逐条对应验收标准："非法字段不会导致 daemon 退出或清空已有配置"（P3+P4）。

## 2. 字段级校验矩阵

> 合法值判定顺序：缺键 → 类型 → 取值域 → 唯一性（对 id）。
> 动作列：**回退**（取缺省并告警）/ **隔离**（条目 quarantine）/ **忽略**（未知键）。

| 字段 | 类型 | 合法值 | 非法值（例） | 非法时动作 | 备注 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `schema_version` | int | **仅 2** | 缺/1/3/`abc` | **隔离** | 版本不符 = 非 v2 条目，其余条目照常；唯一隔离级必判字段 |
| `id` | string | charset `[A-Za-z0-9_.-]`，非空 | 含空格/控制符/中文/空 | **隔离**（空/非法）或**回退**（重派生占位 id） | 唯一性：与注册表已有重复 → 保留先见者，后者隔离 |
| `name` | string | 可打印、≤64 字符 | 含控制符/超长 | 回退：截断 40；空 → `task` | 超长截断属宽容处理 |
| `enabled` | bool | `0` 或 `1` | `yes`/`true`/`2`/空 | 回退：`1` | **不**接受模糊真值（避免语义漂移） |
| `trigger` | string | 非空、可打印、无控制符；**其余任意**（C4 原样） | 空/控制符 | 回退：条目隔离（无触发器 = 无调度依据） | 不做格式白名单——legacy 触发器格式由 daemon 匹配层决定（P1-01 §4.2），模型不收紧 |
| `condition` | string | 可打印、≤256 | 控制符 | 回退：空 | P1 不解释内容；仅存 |
| `action.command` | string | 可打印（允许 `\n` 转义与 `\\` 转义） | 未转义的原始控制符 | 回退：空字符串（空命令 = legacy `sh -c ""` 语义，exit 0） | 命令原样保留（含怪癖残留） |
| `action.notify_start` 等 6 个 bool | bool | `0` 或 `1` | 其他 | 回退：`0` | `action.boot` 同上 |
| `action.msg` | string | 可打印、≤256 | 控制符/超长 | 回退：空 | 双引号形式为 legacy 语义（Q11） |
| `dependency` | list | id 列表（空格分隔），每项须过 id charset | 含非法 id 字符 | 忽略非法项 + 告警，保留合法项 | 空列表合法 |
| `health.type` / `recovery.type` | string | `none`（P1 唯一缺省；其他接受） | 控制符 | 回退：`none` | P1 不定义其他枚举语义 |
| `retry.max` | int | ≥0 | 负值/非数字 | 回退：`0` | |
| `retry.interval` | int | ≥1 | ≤0/非数字 | 回退：`60` | |
| `source.type` | enum | `line` 或 `block` | 其他 | 回退：`line` | |
| `source.line` | int 或 `a-b` | `a≥1，b≥a` | 0/负/`b<a`/非数字 | 回退：条目隔离（无来源 = 无法维护 `id`/审计） | 与实际行号一致性由审计比对（可选） |
| `source.raw` | string | 可打印（转义存储） | 原始控制符未转义 | 回退：空 | 与 `source.line` 一致可审计 |
| `runtime.*`（全部） | 各异 | 见 Schema §5 | 非法 | 回退：类型缺省（state=`idle`，run_count=`0`，余空） | 加载器可整体重置运行时段，但不得影响配置段；历史保留策略属于接线任务 |
| **未知键** | — | — | — | **忽略 + 告警** | 未来扩展字段向后兼容（P1 宽容原则） |
| **非 `key=value` 行**（无 `=`、空行、注释除外） | — | — | — | 忽略该行 + 告警（**不是**条目隔离） | 行级错误不株连条目 |

## 3. 加载流程与条目隔离

```
加载注册表（tasks-v2/）
  ├─ 逐条目文件：
  │    ├─ 逐行：注释/# 跳过；非 key=value → 行级忽略+告警；未知键 → 忽略+告警
  │    ├─ schema_version ≠ 2 → 条目隔离（不读其余字段），继续下一条目
  │    ├─ id 非法/缺 → 隔离；id 重复 → 先见者保留，后者隔离
  │    └─ 其他字段：逐字段校验（§2），非法 → 回退缺省 + 告警
  ├─ 隔离区：条目保留（quarantine 标记）但不参与调度；可审计、可修复后重载
  └─ 汇总：合法条目 + 隔离条目清单（日志）
```

- **隔离 ≠ 删除**：隔离条目留在原处（或隔离目录），供审计/人工修复；
- 单条目失败**不会**中断整个加载（P2）；
- 隔离条目的 `runtime.state` 置 `invalid`（Schema §9）。

## 4. 原子性与持久性

1. **写**：一律先写 `*.tmp`，`sync` 后 `mv` 原子替换；失败时删除 tmp，**原文件不动**。
2. **读**：按条目文件逐个读；**整个注册表加载失败**（目录不可读等）→ 保留内存中
   上一快照、记 ERROR 并继续运行（P4：绝不因读取失败清空已加载集）。
3. **启动**：首次加载为空集合法（= 尚未接线/无任务）；不视为错误。
4. **并发**：daemon 单进程写；本 P1 不引入新锁（沿用现有单实例锁即可）。
5. **单行性**：`key=value` 存储要求转义（`\` → `\\`、真实换行 → `\n`），条目保持
   单行；任何未转义控制字符按行级错误处理（§2 行级忽略）。

## 5. 错误分类与日志

| 级别 | 场景 | 示例（沿用 su-scheduler.log 格式） |
| :--- | :--- | :--- |
| WARNING | 字段回退缺省 / 未知键 / 行级忽略 | `[WARNING] Task <id>: invalid enabled value 'yes', falling back to 1` |
| ERROR | 条目隔离 / 加载失败保留快照 | `[ERROR] Task <id>: schema_version=1 != 2, quarantined (daemon continues)` |
| INFO | 加载汇总 | `[INFO] Task registry loaded: 17 legal, 1 quarantined` |

- 日志不输出字段原文内容（避免刷屏/泄露配置）；输出 `id` 与字段名。
- 告警/错误**绝不**触发 `exit`、`kill`、`rm` 其他条目或清空（P3/P4）。

## 6. "绝不"清单

对任何单条目非法输入，加载/校验实现**绝不**：

1. 绝不 `exit` / `kill $$` / 触发崩溃（P3）；
2. 绝不 `rm`、清空、或裁剪**其他**条目（P4）；
3. 绝不整体丢弃合法条目集（加载失败 → 保留上一快照，§4.2）；
4. 绝不让非法值静默进入内存（必须回退缺省或隔离并告警，§2）；
5. 绝不因字段内容执行命令或展开 shell（存储层纯文本——避免注入面；值仅作数据
   读取，未来执行层另行处理）；
6. 绝不为"通过校验"而改写 `source.raw`/`trigger` 原文（C4 + 转换怪癖保留，
   Schema §8.3）。

> 验收对照：上述清单全部满足 ⇒ "非法字段不会导致 daemon 退出或清空已有配置"。
