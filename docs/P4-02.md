## 2. 裁决落地（ADR 摘要，详见 docs/architecture/dependency-schema.md）

- **D1** 规范保存 = 逗号分隔（`dependency=a,b,c`）；解析容忍空格/制表符；
  规范化写回统一逗号。
- **D2** 单条 entry `[?]<task-id>[:<STATE>]`；`?`=Optional（缺省 Required）；
  STATE ∈ {STOPPED, FAILED}（缺省 STOPPED）；id 过 `[A-Za-z0-9_.-]`、无 `..`/`/`/`*`。
- **D3** condition = 单行可打印 ASCII、≤256、空=无条件恒真；求值归 P4-06。
- **D4** 上限常量 `DEP_MAX=32`/`COND_MAX_LEN=256`（供 P4-10 复用）；仅 managed 域。
- **D5** 非法 → 后端权威拒绝（rc 非 0），原 task 文件/config 逐字节不变（B9）。
